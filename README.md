# YunexalBackrooms (Purpur 26.3)

Повністю кастомний процедурний генератор **Backrooms (Рівень 0 «Лобі»)** з обов’язковим завантаженням ресурс-паку через ізольовану кімнату **Лімбо** та процедурно згенерованим ресурс-паком (текстури + синтезовані OGG-звуки).

## Архітектура

1. **Лімбо-кімната (`world_limbo` + `LimboManager`):**
   - Гравець через `AsyncPlayerSpawnLocationEvent` спавниться у повністю чорному ізольованому боксі з `BLACK_CONCRETE` (`BLINDNESS` + `DARKNESS`, приховування інших гравців).
   - Лише після `PlayerResourcePackStatusEvent.Status.SUCCESSFULLY_LOADED` з відповідним `UUID` гравець переноситься у `Level 0` під звук noclip-переходу; відмова, помилка чи таймаут повертають на `hub1`.
2. **Кастомний генератор Рівня 0 (`Level0ChunkGenerator`):**
   - Безшовна детермінована сітка клітинок `4x4` у макро-регіонах `8x8` із гарантованим обхідним деревом DFS і міжрегіонними проходами.
   - Зони: класичні моно-жовті коридори (`CLASSIC_MAZE`), колонні зали (`PILLAR_HALL`), вузькі лабіринти (`NARROW_MAZE`), темні сектори з мерехтливими/перегорілими лампами (`BLACKOUT_ZONE`), вологі колони, вент-решітки та герметизація бедроком зверху і знизу.
3. **Ресурс-пак (`resourcepack/build_pack.py`):**
   - Генерує 32x32 текстури шпалер, плінтусів, килиму, підвісної стелі, анімованих ламп та 4 аудіо-треки (60Hz гул ламп, тріск мерехтіння, noclip-перехід, глухий стукіт здалеку) під формат Minecraft `26.3` (`min_format: 97`).

## Збірка

### Ресурс-пак
```bash
cd resourcepack
python3 build_pack.py
```

### Плагін (Java 25 / Purpur 26.3)
```bash
mvn clean package
```

У `bukkit.yml` для основного світу потрібно вказати генератор:
```yaml
worlds:
  world:
    generator: YunexalBackrooms
```

## Команди
- `/br info` — поточний світ, координати та статус ресурс-паку
- `/br hub` — повернення на резервний сервер (`hub1`)
- `/br reload` *(OP)* — перезавантаження `config.yml`
- `/br reloadrp [гравець]` *(OP)* — повторно відправити гравця у Лімбо з перевіркою паку
- `/br tp <level0|limbo>` *(OP)* — швидка телепортація між світами
